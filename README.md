## 🚀 Featured Projects

### 🟡 DPG — Digital Present Gateway (SIJA Presensi)
A multi-role, 4-digit code based digital attendance system built for the SIJA classes. Features server-side geofencing (Haversine formula), role-aware dashboards (Admin/Teacher/Homeroom/Head of Concentration/Student), attendance recaps & trend charts, and CI/CD deployment via GitHub Actions.

**Stack:** Laravel · Blade · MariaDB · Docker · Nginx · Tailscale Funnel
**Highlights:** QR-token attendance, dynamic teacher-location geofencing, light/dark mode

---

### 🟡 Computer Lab Monitoring (IoT)
A Laravel-based monitoring app that displays real-time temperature & humidity data from DHT11 sensors over ESP32. Includes a public, login-free dashboard for teachers, plus full-access roles for Lab Staff and Head of Lab.

**Stack:** Laravel · Breeze · ESP32 · DHT11 · Chart.js
**Highlights:** Role-aware dashboard, live temperature/humidity charts, navy-gold-cyan cyber theme

---

### 🟡 Ascension Log (Quest Tracker)
A gamified daily quest & fitness tracker with a Solo Leveling-style status window (level, XP, rank, streak). Started as an HTML/JS prototype, now being rebuilt with Laravel + Livewire as a skill-building exercise.

**Stack:** Laravel · Livewire · Blade
