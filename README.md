# Hey, I'm Apish 👋

I'm a grade 12 student at SMKN 6 Malang (SIJA, if you're wondering), and I like building small web apps that people actually use. Then I deploy them on a home server I run myself.

Most of what I make is **Laravel**. Lately I've been getting into **IoT** too, because watching real sensor data show up on a screen never gets old.

---

### 🔨 What I'm working on

- **[Ascension Log](https://github.com/pishstew/the-ascension-project)** is a daily workout tracker that works like a game: levels, XP, streaks, quests. I built it because I wanted my own workout routine to feel less boring.
- **Temperature, humidity & smoke monitoring** is a school project. ESP32 + sensors send data over WiFi to a dashboard on my server. Repo coming soon.

### 📦 Things I've built

- **DPG (Digital Present Gateway)** is a QR-based attendance system for my class, with role-based dashboards and geofencing so you can't check in from your bed. It's not public yet.
- **Computer lab monitor** is a Laravel dashboard for lab temperature and humidity. Also not public yet.

### 🧰 What I use

`Laravel` · `PHP` · `Livewire` · `MariaDB` · `Docker` · `Tailscale` · `ESP32` · `JavaScript`

### 📚 Learning right now

JavaScript fundamentals (slowly working through The Odin Project), cleaner Laravel structure, and getting better at Docker.

---

Everything I build ends up running on my own server, so if something's down, I'm probably debugging it. 😅

Feel free to look around. If something looks interesting, say hi!
